# 권한·비용·오류·출처 점검

최종 프로젝트 제출 전 점검표다.

## 권한 점검

- [ ] AI에 연결한 권한이 최소 권한 원칙에 맞는가
- [ ] 읽기 전용으로 충분한 업무에 쓰기 권한을 주지 않았는가
- [ ] 연결 기간에 제한을 두었는가
- [ ] 실습에 실제 계정이나 실제 파일을 연결하지 않았는가

## 비용 점검

- [ ] 유료 API나 유료 계정이 필요한 실습이 있는가
- [ ] 있다면 사전조건과 비용 발생 가능성을 적었는가
- [ ] 계정 없는 독자를 위한 대체 실습이 있는가

## 오류 점검

- [ ] 각 장의 자가 점검표를 모두 통과했는가
- [ ] 수정 전후 비교 기록이 있는가
- [ ] 흔한 오류와 해결책을 확인했는가

## 출처 점검

- [ ] 모든 외부 자료에 제목·발행처·URL·열람일을 표시했는가
- [ ] 날짜가 사건일과 공개일로 구분되었는가
- [ ] 확인되지 않은 내용은 미확인으로 표시했는가
- [ ] 원문 전문이나 이미지를 복제하지 않았는가
