# 결과와 수동 검증

이 파일은 독자가 실습 결과를 기록하는 양식이다. 아래 예시는 가상의 작성 예다.

## 작성 예 (가상)

- 1장 결과: 가상 일정 정리 업무를 4가지 행동으로 분해. 전송과 삭제의 위험도를 높음으로 표시. 수동 검증: 원문의 일정 4건이 빠짐없이 분류됨.
- 2장 결과: 가상 고객 문의 10건을 민감도별로 분류. 원문 재출력 없음 확인. 수동 검증: 결제·건강·주민등록번호 관련 3건이 최고 민감도로 분류됨.
- 3장 결과: 가상 파일함의 권한 매트릭스 작성. 회의록 폴더 읽기만 허용. 수동 검증: 재무·인사 폴더가 제외됨.
- 4장 결과: 가상 문서에서 근거 내용만 요약, 숨은 지시 미실행. 수동 검증: "최고라고 평가" 표현이 결과에 없음.
- 5장 결과: 가상 이메일 발송의 승인 카드 5줄 완성. 실제 전송 없음. 수동 검증: 받는 사람과 첨부가 원문과 일치.
- 6장 결과: 출처 3개의 주장 비교표. 날짜 구분 완료. 수동 검증: 보도일을 사건일로 쓰지 않음.
- 7장 결과: 가상 공유 사건 대응 카드. 순서 확인. 수동 검증: 보고와 기록 포함.
- 8장 결과: AI 업무 위임 정책 1페이지와 업무별 승인표. 수동 검증: 여섯 가지 항목 모두 포함.

## 수동 검증 방법

1. 각 결과를 원문(가상 자료)과 대조한다.
2. 부록 A의 평가 기준과 비교한다.
3. 다른 점이 있으면 수정하고 수정 전후를 기록한다.
