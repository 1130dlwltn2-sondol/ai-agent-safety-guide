# 최종 프로젝트: 나만의 안전 사용 규칙

## 목표

1장부터 7장까지 배운 안전 습관을 한 장짜리 실행 문서로 통합한다. 독자가 스스로 재현할 수 있는 형태로 만든다.

## 입력 자료

- 각 장의 실습 결과물 (행동 분류표, 민감도 분류, 권한 매트릭스, 승인 카드, 사실 확인 표, 대응 카드)
- 가상의 업무 목록 4건 (8장 참조)
- 모든 자료는 가상의 합성 자료다. 실제 개인정보를 사용하지 않는다.

## 재현 절차

1. 각 장의 자가 점검표를 확인하고 빠진 실습이 없는지 본다.
2. 8장의 복사용 프롬프트로 AI 업무 위임 정책 1페이지를 만든다.
3. 업무별 승인표를 만든다.
4. project/results.md에 결과와 수동 검증을 기록한다.
5. project/checklist.md의 항목을 하나씩 확인한다.

## 제출물

- prompts.md: 사용한 프롬프트와 버전
- results.md: 결과와 수동 검증
- checklist.md: 권한·비용·오류·출처 점검
- references.md: 사용한 공식 자료
