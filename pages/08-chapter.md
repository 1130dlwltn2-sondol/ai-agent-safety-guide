# 8장. 완성 프로젝트: 나만의 안전 사용 규칙

## 학습 목표

1. 1장부터 7장까지의 규칙을 한 장짜리 실행 문서로 통합할 수 있다.
2. 업무별로 승인 기준을 달리한 승인표를 만들 수 있다.

## 선행 개념

7장까지 배운 내용을 한 장에 모은다. 선행 개념은 각 장의 산출물이다. 1장의 행동 분류표, 2장의 민감도 분류, 3장의 권한 매트릭스, 4장의 숨은 지시 대응, 5장의 승인 카드, 6장의 사실 확인 표, 7장의 대응 카드가 재료다.

용어 정리:
- 사용 정책: AI를 쓸 때 지키기로 한 나만의 규칙 문서.
- 업무별 승인표: 업무마다 어떤 행동에 누구의 승인이 필요한지 정리한 표.
- 데이터 등급: 자료를 민감도에 따라 나눈 등급. 예: 공개, 내부, 민감, 매우 민감.

## 쉬운 설명

지금까지 배운 것은 각각 따로 보면 작은 습관이다. 하지만 모아 두면 "나만의 안전 사용 규칙"이라는 문서가 된다. 이 문서는 한 장이면 충분하다. 길면 지키지 않게 되기 때문이다.

한 장짜리 정책에 들어갈 여섯 가지:

1. 데이터 등급: 어떤 자료를 AI에 넣어도 되는지 등급으로 정한다.
2. 권한: 연결할 때 기본으로 주는 권한과 주지 않는 권한을 적는다.
3. 금지 행동: 승인 없이 하지 않는 행동 목록. 전송, 결제, 삭제, 게시가 기본이다.
4. 사전 승인: 승인 카드가 필요한 경우와 승인자를 적는다.
5. 사후 기록: 작업 뒤에 무엇을 기록하는지 적는다.
6. 검증 기준: 결과를 어떻게 확인하는지 적는다.

업무별 승인표는 업무마다 승인 기준을 다르게 한 표다. 일정 정리는 본인 확인만으로 되지만, 외부 발송은 한 번 더 확인하는 식이다.

이 책의 원칙을 마지막으로 확인한다. 이 교재는 법률 자문이 아니라 실무 안전 습관을 다룬다. 규제는 나라마다 다르고, 제품 화면은 바뀔 수 있다. 기준일(2026-10-11) 이후의 변경은 공식 문서를 다시 확인한다.

### 실습 과제

개인 AI 사용 정책 1장 + 업무별 승인표 제작.

### 복사용 프롬프트

```
앞의 모든 실습을 바탕으로 AI 업무 위임 정책 1페이지를 작성해줘. 데이터 등급, 권한, 금지행동, 사전 승인, 사후 기록, 검증 기준을 포함해줘.
```

### 예상 결과

AI는 대략 다음과 같은 1페이지 정책을 돌려준다.

AI 업무 위임 정책 (가상 예시, 1페이지)
- 데이터 등급: 공개, 내부, 민감, 매우 민감. 민감 이상은 가명 처리 후 입력.
- 권한: 기본은 읽기 전용. 쓰기는 업무별로 승인 후 부여. 공유·삭제는 부여하지 않음.
- 금지 행동: 승인 없는 외부 전송, 결제, 삭제, 공개 게시.
- 사전 승인: 외부 발송과 삭제는 승인 카드 작성 후 진행.
- 사후 기록: 작업 내용, 사용 자료, 승인 여부를 메모에 기록.
- 검증 기준: 날짜는 사건일과 공개일 구분, 수치는 원문 대조, 미확인은 미확인 표기.

업무별 승인표 (가상 예시):
| 업무 | 승인 기준 |
|------|-----------|
| 가상 회의록 요약 | 본인 확인 |
| 가상 고객 안내 메일 | 승인 카드 작성 후 발송 |
| 가상 일정 정리 | 본인 확인 |
| 가상 보고서 초안 | 본인 확인, 외부 공유 시 승인 카드 |

### 흔한 오류와 해결책

- 오류: 정책이 세 장이 되었다. 해결: 한 장에 들어갈 여섯 가지 항목만 남기고 나머지는 부록으로 뺀다.
- 오류: 검증 기준이 빠졌다. 해결: 6장의 "날짜 구분, 원문 대조, 미확인 표기"를 넣는다.
